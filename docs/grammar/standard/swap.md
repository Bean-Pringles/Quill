# swap

## Syntax

Print accepts two arguements, the two variables to swap values

```code
swap(<var 1>, <var 2>)
```

## Examples

```python
let x: string = "World!"
let y: string = "Hello,"

swap(x, y)

print(x)
print(y)
```

This will print "Hello," on one line and "World!" on a separate line.

```python
let x: int = 3
let y: int = 4

swap(x, y)

print(x)
```

This will print "4" to the console.
